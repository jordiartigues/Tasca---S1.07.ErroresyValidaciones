# Tasca S1.07 - Errors i Validacions

**Descripció:** Exercicis per practicar la gestió d'errors i la validació de dades en PHP, treballant amb formularis, comprovació de camps i expressions regulars.

## Tecnologies

- PHP
- XAMPP
- Visual Studio Code

## Instal·lació

1. Clonar el repositori:

```bash
git clone https://github.com/jordiartigues/Tasca-S1.07.ErroresyValidaciones.git
```

2. Obrir el projecte amb Visual Studio Code.

3. Per executar el primer exercici des de la terminal, entrar a la carpeta del projecte:

```bash
cd Tasca-S1.07.ErroresyValidaciones
```

4. Entrar a la carpeta dels exercicis:

```bash
cd "Nivell I"
```

5. Executar el primer exercici:

```bash
php exercici1.php
```

6. Per executar el segon exercici, iniciar Apache des del panell de control de XAMPP i obrir el formulari al navegador:

```text
http://localhost/Tasca-S1.07.ErroresyValidaciones/Nivell%20I/exercici2.html
```

El formulari envia les dades a `exercici2.php`, que processa i valida la informació introduïda.

## Estructura del projecte

```text
Tasca-S1.07.ErroresyValidaciones/
└── Nivell I/
    ├── exercici1.php
    ├── exercici2.php
    └── exercici2.html
```

## Demo

Els exercicis s'executen localment amb PHP i XAMPP. No hi ha demo online perquè es tracta d'exercicis de PHP.
